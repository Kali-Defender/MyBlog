很多新手安装完 Ubuntu 24.04 Server 极简服务器版后，会发现系统没有图形化网络设置界面，只能通过 **netplan** 命令配置网络。

本文为纯实战教程，适配 **Ubuntu 24.04 Server LTS** 版本，包含两种核心网络模式：适合日常测试的自动DHCP获取IP、适合工作/服务器环境的静态固定IP，全程无废话、可直接跟着操作，规避断网、配置报错、IP冲突等常见问题。

**前置说明**：Ubuntu 20.04+ 版本统一采用 netplan 工具管理网络，废弃了传统 /etc/network/interfaces 配置，本文配置仅适配新版系统，兼容性拉满。

## 一、自动获取IP配置（DHCP模式｜非工作环境）

### 1. 适用场景

个人测试、临时使用、不需要固定服务器IP的场景，系统开机自动从路由器/网关获取IP，无需手动配置，零门槛上手。

### 2. 模式优缺点

- **优点**：自动适配局域网网络，彻底避免手动配置导致的IP地址冲突，无需手动维护配置
    
- **缺点**：每次重启服务器、重启网络后，获取的IP地址可能发生变化，不适合远程连接、项目部署、服务器运维场景
    

### 3. 查看当前网络配置

netplan 的所有网络配置文件均存放在 `/etc/netplan/` 目录下，首先查看目录下的配置文件（文件名每台机器不同，一般为 00-installer-config.yaml 、01-network-manager-all.yaml）。

```bash
# 查看netplan配置文件
ls /etc/netplan/

# 查看配置文件内容（替换为你自己的文件名）
cat /etc/netplan/xxx.yaml
```

### 4. 配置生效判断

打开配置文件后，若文件中包含 **`dhcp4: true`**，代表当前系统已开启 IPv4 自动获取IP模式，即为DHCP自动网络配置。

## 二、固定静态IP配置（静态模式｜工作/生产环境）

### 1. 适用场景

服务器运维、项目部署、远程SSH连接、固定设备地址等正式场景，**必须配置静态IP**，保证服务器IP永久不变。

### 2. 实操配置步骤

编辑 netplan 目录下的默认网络配置文件，全程严格遵循 yaml 语法（**极其重要**：yaml 靠缩进识别层级，必须用空格缩进，禁止使用Tab键，否则配置直接报错）。

```bash
# 编辑网络配置文件
vim /etc/netplan/xxx.yaml
```

### 3. 标准静态IP配置模板（已修复官方常见错误）

适配 Ubuntu 24.04 Server 通用模板，可直接复制使用，按需修改IP、网关即可。修正了原生配置 `nameservers` 缩进错误（原错误配置会导致DNS失效、无法联网）。

```yaml
network: 
  version: 2 
  ethernets: 
    ens33:      # 网卡名称（通过ip a可查看自己的网卡名）
      dhcp4: false  # 关闭自动DHCP，开启静态IP
      addresses: 
        - 192.168.118.134/24  # 本机静态IP+子网掩码
      routes: 
        - to: default 
          via: 192.168.118.2   # 网关地址
      nameservers: 
        addresses: 
          - 223.5.5.5       # 阿里公共DNS
          - 114.114.114.114 # 国内通用DNS
```

### 4. 关键参数说明（新手必看）

- **网卡名 ens33**：虚拟机默认网卡名，物理机可能为 eth0、enp0s3 等，执行 `ip a` 查看本机真实网卡名并替换
    
- **IP/24**：24代表子网掩码 255.255.255.0，根据自己局域网网段修改IP
    
- **网关地址**：必须和自己电脑、局域网网关一致，否则无法联网
    
- **DNS服务器**：选用国内公共DNS，解决ping不通域名、无法上网的问题
    

### 5. 安全测试配置（防止断网翻车）

重点！修改网络配置后，**不要直接apply生效**，先测试配置语法和连通性，配置错误会自动回滚，杜绝服务器断网无法连接的问题。

```bash
netplan try
```

出现 **Configuration accepted** 提示，代表配置无误，按下 **回车键** 临时确认保存；若报错，会精准提示错误行号，基本都是缩进、语法、参数填写错误。

### 6. 正式应用网络配置

测试通过后，执行命令永久生效配置，无需重启服务器。

```bash
netplan apply
```

## 三、配置验证（确认网络生效）

配置完成后，通过以下命令验证IP和网络状态：

```bash
# 查看本机IP地址
ip a

# 测试外网连通性
ping www.baidu.com
```

## 四、新手常见踩坑总结

1. **yaml语法报错**：绝对不能用Tab缩进，所有层级统一用2个/4个空格，全程保持缩进一致
    
2. **DNS无法生效**：nameservers 必须和 ens33 同级缩进，不能错位
    
3. **无法联网**：检查网关、IP网段是否和宿主机局域网一致
    
4. **直接apply翻车**：生产环境务必先执行 netplan try 测试，避免断网
    

## 五、总结

1. 测试环境优先使用 **DHCP自动获取IP**，简单零配置，避免IP冲突；

2. 工作、服务器环境必须配置 **静态固定IP**，保证设备地址永久固定，适配远程运维；

3. Ubuntu 24.04 网络核心：netplan 配置 + yaml规范语法 + 先测试后生效，是配置不翻车的关键。
